# 2026-11-05

## Literature search is done with Claude Code

> 그럼 클로드 코드로 서칭하는거로 하자.

[Then let's do the searching with Claude Code.]

Said after a side-by-side that a separate session ran on one rheology topic, constitutive models for thixotropic elasto-viscoplastic materials, and kept outside this repository in that session's scratchpad. What the person had in front of them when they decided:

- Claude Code with its web search alone returned papers that were nearly all on topic, but it missed many of the classic ones (Saramito's elasto-viscoplastic models, the kinematic-hardening model of Dimitriou and McKinley, the structural-kinetics papers of Mujumdar and of Dullaert and Mewis).
- The same Claude Code with OpenAlex as a scholarly index, a few keyword searches, one hop along references and citations, and its own reading of the ranked titles found roughly three times as many relevant papers. A blind judge, itself a model, made the relevance calls; they are inferences, not ground truth.
- The dedicated agents did not help on this topic: the PaSa demo searches arXiv only and returned no paper; Asta asks for its terms to be accepted before a query, and the person chose to leave it out.
- Published benchmarks where dedicated agents lead were run mostly on computer-science papers.
- Full text: the open tools reach open-access copies only; a subscription paper reaches an agent only through a person's own download. Stanford guidance read the same day (the GSB library usage policy and the Teaching and Learning Hub) warns against putting licensed or copyrighted material into external AI tools and against systematic downloading.

The person's words settle the direction: no dedicated paper-search project is adopted; searching stays with Claude Code. The form is a recommendation and is not confirmed:

1. The search runs on a scholarly index (OpenAlex, with Semantic Scholar as a second source), keyword search plus one hop of citation expansion, and Claude reads and selects; general web search is a supplement.
2. Open-access full text is fetched only from the indexes' open links; a subscription paper enters only when the person downloads it and drops it into `meta_agent/inbox/materials/drop/`, and `may_quote` is the person's word. No university login, proxy session or cookie is handed to an agent (meta_agent Tier 0).
3. API keys for OpenAlex or Semantic Scholar, if wanted, are requested by the person; the anonymous budgets ran out during the comparison.
4. Whether licensed full text may be read by Claude at all is a question for Stanford Libraries before any paywalled PDF is given to an agent.

Nothing in `plan.md` changes until the person says so.
