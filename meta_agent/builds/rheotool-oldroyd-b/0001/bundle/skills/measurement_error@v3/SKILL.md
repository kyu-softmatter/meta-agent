# measurement_error

**Gives:** the error, the measured value minus the reference value, and its magnitude, the error without its sign.

**Needs:** the measured value and the reference value, both in the quantity's unit.

**When it applies:** any comparison of a measured value with a reference value of the same quantity: a run against a published value, a computation against a stated one.

**What it never does:** judge the comparison. Whether the magnitude is small enough is a tolerance a person chooses.

Run it through the runner; never type its result.
