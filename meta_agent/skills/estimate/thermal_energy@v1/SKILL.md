# thermal_energy

**Gives:** `thermal_energy`, k_B T in joules.

**Needs:** `temperature`, in kelvin.

**When it applies:** any absolute temperature.

**What it does not say:** which temperature to choose, or kT in an engine's own unit. The first is a person's; the second is unit_convert's, through a confirmed scale.

Run it through the runner; never type its result.
