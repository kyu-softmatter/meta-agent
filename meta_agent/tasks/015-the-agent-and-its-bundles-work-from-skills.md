**Two words kept apart (plan.md 14-38(a)):** a *library skill* is source code with a manifest and worked cases under `meta_agent/skills/` or a bundle's `skills/` (check 22). A *session skill* is a procedure in `.claude/skills/<name>/SKILL.md` that a session loads when its description matches. This task writes session skills and changes no library skill.
