**Method (recommended, not settled):**
- Design seat: `contracts/core.json` lists the paths and rules of plan.md 5.5's core (MP1, MP4, MP10, MP11, `grades.json`, `seats.json`, the hook, SMA §8.3 rules 1–5, a bundle's `envelope/` and `approvals/`, the Lab Profile's policy fields, safety policy and execution permission). Check 9 (`kind` one of `tighten | loosen | reshape | retire`; `loosen`, `retire` and `touches_core: true` need `persons_words` with a `docs/ideas/` commit that contains them; `tighten` needs `proof.fixture`), check 10 (a ledger line's proposal and commit exist; `cost` fields present), check 13 (`edit_rows[].verdict` one of four; an `experience` whose verdicts are all `confounded` is refused from `library/`; more than one changed component or fewer than two rollouts makes every verdict `confounded`), check 14 (`held[]` items absent from the bundle; a release needs `persons_words` and a commit), each with rejected fixtures under `check09_*/` to `check14_*/`; the pre-commit hook refuses a commit that removes an implemented check id from `IMPLEMENTED` or `B_IMPLEMENTED` without a `Removes-check: <ids>` trailer, with a history fixture; plan.md 8 marks the four implemented.
- Meta seat, observe: `src/harness/observe.py` reads `failures.jsonl`, the last verdict lines of `validate.py` runs kept under `harness/verdicts/`, refusal cards, `git log --format=%H %s` for commits whose message or hook log shows `--no-verify`, the read-only paths of `envelope/observed.json` (with the commit hash read; `degraded` when unreachable) and `onboarding_record` questions marked unnecessary, and appends `harness_incident` drafts to `harness/incidents.jsonl` with a stable id derived from the source line, so a second run appends nothing. Classification: the model's draft of `cause_class` against `case_classes.json`, `path: undecided`; every incident also becomes a draft case through `006`'s writer.
- Meta seat, propose and prove: a proposal is `harness/proposals/<id>/{proposal.json, change.diff}`; `touches_core` is computed by matching the diff's paths and the rule ids it names against `core.json`. `src/harness/prove.py <id>` takes the parent commit's validator with `git show <sha>:contracts/validate.py` into a temporary directory (no worktree, plan.md 9), runs it on the proposal's fixture before and after the diff, runs the affected bundles' `replay/` before and after and counts `new_fail`, and writes `proof.{fixture_before, fixture_after, replay_new_fail, ran_at, validator_sha}`; a proof field present without `prove.py`'s `ran_at` and `validator_sha` is what check 9 refuses. The owning seat lands the diff; the harness writes nothing outside `harness/`.
- Meta seat, measure: `src/harness/ledger.py` appends a line with configuration `{model, runner, k, seed}`, rollouts, tokens, wall-clock, cost (provider-stated or `computed` and marked so), the verdicts of `edit_rows`, and `confounded` applied by the rule; `experience` cards enter `library/<domain>/<build_id>/` only when a verdict is not `confounded`, else `NO_ENTRY` is recorded on the ledger line. A revert is a new revision with `reverted_by` on the ledger. `src/harness/retro.py <from> <to>` writes `harness/retro/<date>.json` from the period's incidents, proposals and ledger, with counts and ids only, no prose.
- Meta seat, evaluation: `src/harness/four_conditions.py` runs the echo task set in mock under C0 (the template as is), C1 (`degraded: [knowledge]`), C2 (`degraded: [cases]`) and C3 (both), baseline first, writing `eval/<set>/<cond>/` with each run's verdicts and the comparison; a failed baseline makes the set ungraded; `k` is 1 and read from a flag. A threshold the person must choose is shown as a curve read off replay (tolerance against refusal rate) written to `eval/<set>/curves/`, and the code picks no point.
- Tests: observe on a fixture `failures.jsonl` and verdict file writes the expected incidents and appends nothing on a second run; `prove.py` on a fixture proposal that tightens check 2 writes `fixture_before: FAIL`, `fixture_after: PASS`, `replay_new_fail: 0`; a proposal with two changed components gets every verdict `confounded` and `NO_ENTRY`; a `loosen` without `persons_words` is rejected by `--expect-fail`; the four conditions on the echo set write four folders and a comparison; the hook fixture refuses a removal without the trailer.
